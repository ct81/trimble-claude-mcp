RoachHarbor

Connected workflows for architecture, engineering, and construction.

RoachHarbor is the brand of the Trimble Claude MCP application and its Workflow Builder. Developer and support contact: noodletan@outlook.com.

RoachHarbor brings project files, spreadsheets, Trimble Connect operations, and connected tools into a visual Workflow Builder. Build a workflow to import information, process it, call an API or MCP tool, and display or export the result.

Project Data and Connected Tools

Files and Results

Import PDF, Excel, CSV, IFC, and DXF files. Use connected extraction or conversion tools, inspect results in grid or form views, and export supported results to Excel or CSV.

Trimble Connect

Sign in with Trimble to use available project, file, model, organizer, property-set, topic, and Status Sharing operations through MCP tools.

APIs and Local Bridges

Connect REST APIs and MCP services to workflow data. Tekla, TSD, and SketchUp integrations depend on the corresponding configured bridge or service; cloud hosting alone cannot access software on your workstation.

Optional Claude AI

Ask Claude questions or connect a Claude component to analyze workflow input. AI features require a configured server-side Anthropic integration. Review generated answers before using them for project decisions.

Connect Your Google Sheets

The Google Sheets import component lets you sign in with your own Google account, discover spreadsheets in Drive, select a sheet, and import its rows into a workflow.

  • Read-only Drive access discovers spreadsheet names and identifiers.
  • Read-only Sheets access discovers sheet names and reads rows from your selected sheet.
  • These permissions cover more than one selected file. Drive access supports spreadsheet discovery, while Sheets access supplies the row data used by your workflow.
  • The component does not request permission to edit or delete your Google files. Google authorization is handled by Google; RoachHarbor does not ask for your Google password.

A configured Google OAuth client is required. While that OAuth app is in Testing mode, only accounts approved as test users can sign in.

Imported rows can be displayed or exported. If you connect them to Claude, MCP tools, or REST API components, running the workflow can send that data to those destinations. Review the workflow before running it.

Saved Workflows and Messaging

Save named workflows for reuse. Server storage uses Firebase Realtime Database when configured, with local server-disk storage as a fallback. Uploaded files can be included in server-saved workflows.

Scheduled workflows run in your browser while the page is open. WhatsApp and Telegram integrations are available when configured by the operator and require the relevant account authorization.

Your Data and Privacy

Trimble sign-in supplies account and project information and authorization tokens so the application can associate your session with your account and perform authorized project operations. Imported files and spreadsheet rows provide the input for extraction, conversion, analysis, and exports. Saved workflow names, settings, and schedules let you reuse those operations.

Account connections and workflow choices determine what information is processed. Settings and local workflow copies are stored in your browser; saving workflows or running connected components can send information to the application server and selected providers.

Google Sheets authorization tokens are held in browser memory. Selected spreadsheet identifiers and sheet names can be saved with a workflow. Claude components send your prompt and connected workflow context to the server and Anthropic; API and MCP components send configured input to their selected services.

You can choose whether to connect accounts and can revoke Google access through your Google Account settings. This homepage and the privacy policy are public; account authorization is needed only for connected application features.

Read our Privacy Policy for details about Google data access, AI requests, storage, third-party services, and deletion options.
